# TQC VIP 離線練習

學生修改 `questions/Q110.py`，執行評分器並輸入 `Q110`，即可知道是否通過。
包含 VIP 的 16 題、61 組測資；只需 Python 3.9 以上，不需安裝套件，也不需連線。

## 開始練習

1. 將整個 `tqc_practice` 資料夾複製到自己的電腦，使用 VS Code 或其他編輯器開啟。
2. 讀取 `questions/Q110.md` 的題目，編輯旁邊的 `questions/Q110.py`。
3. **存檔**。
4. 在此資料夾的終端機執行：

   ```sh
   python grade.py
   ```

   macOS 若找不到 `python`，請使用 `python3 grade.py`。
   Windows 也可雙擊 `start.bat`；macOS 可使用 `start.command`（終端機啟動最可靠）。

5. 輸入 `Q110`。評分器會自動餵入測資，不必自己輸入題目要求的數字。
6. 若未通過，查看第一個失敗案例，回去修改、存檔，再輸入 `Q110`。

作答檔一開始只有註解，所以在完成程式前出現「尚未通過」是正常的。
不要將答案寫在 `grade.py`；請寫在對應的 `questions/Qxxx.py`。

## 指令

| 指令 | 用途 |
| --- | --- |
| `Q110`、`110`、`Q110.py` | 評分該題 |
| `list` | 列出題目 |
| `show Q110` | 在終端機閱讀題目 |
| `all` | 評分全部 16 題 |
| `exit` | 結束 |

也可以一次評一題：

```sh
python grade.py Q110
python grade.py all
python grade.py Q110 --strict
```

命令列評分：全部通過回傳 exit code 0，未通過回傳 1，題號格式錯誤回傳 2。

## 評分規則

- 每組測資獨立執行，預設限時 3 秒。標準輸出或錯誤輸出各限 64 KiB。
- 所有測資通過才顯示「全部通過」。練習分數是通過比例，**不是官方配分**。
- 比對輸出文字，包含大小寫、數字格式、行首空白、行內空白及中間的空白行。
- 預設練習模式忽略每行最後的空格／tab，以及輸出最後的換行差異。
- `--strict` 連上述差異也比對，僅統一 Windows/macOS 的換行符號。此選項是本工具的嚴格比較，並非宣稱官方如此評分。
- Q502、Q510 另外檢查是否有頂層 `compute` 函式及指定參數數量；不驗證所有演算法或函式呼叫方式。
- 不要額外印出除錯訊息或自創輸入提示。Q702、Q710 題目指定的提示則必須保留。
- Q710 使用管線輸入，不回顯輸入文字，`Key: Value: ...` 連在一起是正常情況。
- 失敗時顯示第一組失敗案例。`\n` 表示換行，`\t` 表示 tab；可據此找出看不見的格式差異。

## 檔案題

Q902 的 `read.txt`、Q906 的輸入檔案都由評分器自動建立。每組測資在新的暫存資料夾執行，完成後清除，因此不會因上一次練習取代過文字而影響下一次。

請直接 `open("read.txt", ...)` 或開啟題目輸入的檔名，**不要寫死自己電腦的絕對路徑**。
Q906 除了畫面輸出，還會檢查寫回的檔案；檔案空白與換行都會精確比對（僅統一換行符號）。
若要直接執行學生的檔案而不透過評分器，必須自行準備相應的輸入檔案。

## 給老師

可直接將整個資料夾發給學生；沒有附完整解答。測資放在 `data/cases.json`，方便老師調整，也可被學生看到，因此適用自主練習，不適用防作弊正式考試。

每題有 `.md` 題目與空白 `.py` 作答檔。預設不建立成績紀錄、不上傳資料。
可請學生展示「全部通過」，再抽一題請他們解釋程式或關閉答案重寫。

本練習依本專案 `TQC-PY/vip` 程式行為及可用題目整理，測資為自行編製，**未取得官方隱藏測資，不能保證通過本工具就通過官方平台**。

既有 `doc/` 的 Q702、Q710、Q802、Q810、Q902、Q906 部分內容與 VIP 程式不一致，這裡已明確採用 VIP 版本並重新撰寫說明。Q404 以字串反轉、保留前導零；Q510 採正常費氏數列輸出，不包含 VIP 教學檔中的追蹤訊息。若使用的考試版本不同，請先依正式題目調整本工具測資。

評分器在本機以目前使用者權限執行學生程式。暫存目錄、時間與輸出上限是練習保護，**不是安全沙箱**；只執行自己的練習程式，不作為公開上傳程式碼的服務。
