# Q902 資料加總

不從鍵盤輸入資料。讀取目前工作目錄的 read.txt，將以空白、換行或 tab 分隔的整數全部加總後輸出。評分器每次自動提供新的 read.txt。

## 作答方式

編輯 `Q902.py`，存檔後執行 `python grade.py Q902`，或在評分器內輸入 `Q902`。

## 範例輸入

```text
```

本題不需要鍵盤輸入。

評分器提供 `read.txt`，其精確內容（\n 代表換行）：

```text
'10\n20\n30\n'
```

## 範例輸出

```text
60
```

精確輸出表示（可看見空格與換行）：

```text
'60\n'
```
