# Q802 字元對應

輸入一行字串（測資使用 ASCII 字元）。逐字輸出 ASCII code for '字元' is 整數代碼，最後另起一行輸出所有代碼總和。空格也是字元。使用 ord() 取得代碼。

## 作答方式

編輯 `Q802.py`，存檔後執行 `python grade.py Q802`，或在評分器內輸入 `Q802`。

## 範例輸入

```text
Az
```

## 範例輸出

```text
ASCII code for 'A' is 65
ASCII code for 'z' is 122
187
```

精確輸出表示（可看見空格與換行）：

```text
"ASCII code for 'A' is 65\nASCII code for 'z' is 122\n187\n"
```
