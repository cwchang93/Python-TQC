# Q308 各位數總和

第一行輸入測試筆數 n，接著 n 行各輸入一個整數 x（0 ≤ x ≤ 1000000）。每筆輸出 Sum of all digits of x is y，其中 y 為各位數總和。

## 作答方式

編輯 `Q308.py`，存檔後執行 `python grade.py Q308`，或在評分器內輸入 `Q308`。

## 範例輸入

```text
1
98765
```

## 範例輸出

```text
Sum of all digits of 98765 is 35
```

精確輸出表示（可看見空格與換行）：

```text
'Sum of all digits of 98765 is 35\n'
```
