# Q710 詞典搜尋

反覆使用 input("Key: ") 讀入 key；key 為 end 時停止，否則以 input("Value: ") 讀入 value 存入字典。結束後用 input("Search key: ") 讀入欲查詢的 key。存在輸出 True，不存在輸出 False。輸入文字不會被評分器回顯，所以提示文字會接在一起，這是正常的 stdout。

## 作答方式

編輯 `Q710.py`，存檔後執行 `python grade.py Q710`，或在評分器內輸入 `Q710`。

## 範例輸入

```text
a
1
b
2
end
b
```

## 範例輸出

```text
Key: Value: Key: Value: Key: Search key: True
```

精確輸出表示（可看見空格與換行）：

```text
'Key: Value: Key: Value: Key: Search key: True\n'
```

這是依本專案 VIP 版本整理的課堂練習規格，非官方題庫或評分保證。
