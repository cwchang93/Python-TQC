# Q810 最大值與最小值之差

第一行輸入測試筆數 k。接著 k 行，每行有多個以空白分隔的數字，可能包含負數與小數。每筆輸出最大值減最小值，固定小數點後 2 位。

## 作答方式

編輯 `Q810.py`，存檔後執行 `python grade.py Q810`，或在評分器內輸入 `Q810`。

## 範例輸入

```text
2
1 5 3
-2.5 4.25 0
```

## 範例輸出

```text
4.00
6.75
```

精確輸出表示（可看見空格與換行）：

```text
'4.00\n6.75\n'
```
