# Q906 字串資料取代

分三行輸入檔名、舊字串 s1、新字串 s2。讀取 UTF-8 檔案，先 print("=== Before the replacement") 再 print(原內容)；將全部 s1 取代成 s2，print("=== After the replacement") 再 print(新內容)，最後將新內容寫回同一檔案。原內容若含結尾換行，print 會再增加換行。評分會檢查輸出及實際檔案內容。

## 作答方式

編輯 `Q906.py`，存檔後執行 `python grade.py Q906`，或在評分器內輸入 `Q906`。

## 範例輸入

```text
read.txt
world
Python
```

評分器提供 `read.txt`，其精確內容（\n 代表換行）：

```text
'hello world'
```

## 範例輸出

```text
=== Before the replacement
hello world
=== After the replacement
hello Python
```

精確輸出表示（可看見空格與換行）：

```text
'=== Before the replacement\nhello world\n=== After the replacement\nhello Python\n'
```
