# Q702 數組合併排序

先輸出 Create tuple1:，逐行讀入整數，遇到 -9999 結束第一組（不納入數組）。再輸出 Create tuple2: 並用相同方式讀第二組。合併成 tuple，輸出 Combined tuple before sorting: 後接一個空格及合併數組；再輸出 Combined list after sorting: 後接一個空格及由小到大排序的 list。保留重複值。

## 作答方式

編輯 `Q702.py`，存檔後執行 `python grade.py Q702`，或在評分器內輸入 `Q702`。

## 範例輸入

```text
1
5
3
-9999
2
4
6
-9999
```

## 範例輸出

```text
Create tuple1:
Create tuple2:
Combined tuple before sorting: (1, 5, 3, 2, 4, 6)
Combined list after sorting: [1, 2, 3, 4, 5, 6]
```

精確輸出表示（可看見空格與換行）：

```text
'Create tuple1:\nCreate tuple2:\nCombined tuple before sorting: (1, 5, 3, 2, 4, 6)\nCombined list after sorting: [1, 2, 3, 4, 5, 6]\n'
```
