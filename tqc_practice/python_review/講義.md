# TQC VIP Python 語法講義

這份講義整理本專案 VIP 題目常用的語法，適合邊執行範例、邊解釋程式。括號中的題號是相關題型，範例用來理解語法，不一定是該題的完整答案。建議先講輸入、判斷和單層迴圈，再講串列、字典與雙迴圈。

## 1. 輸入、型別轉換與輸出（Q110、Q204）

`input()` 接收一行文字，結果是 **字串**。即使輸入 `12`，得到的也是 `"12"`，想做整數運算要先使用 `int()`；小數則使用 `float()`。

```python
a = int(input())
b = int(input())
print(a + b)
```

輸入兩行 `12`、`3`，輸出是 `15`。如果沒有轉型，`"12" + "3"` 會變成 `"123"`。`print(a, b)` 預設在兩個值之間加一個空格，結尾換行。

## 2. 算術、餘數與整除（Q204、Q308）

```python
print(17 / 5)   # 3.4：一般除法
print(17 // 5)  # 3：整數除法
print(17 % 5)   # 2：餘數
```

`%` 常用來判斷是否整除：`number % 2 == 0` 表示偶數。對非負整數，`number % 10` 可取最後一位，`number // 10` 可去掉最後一位，例如 123 分別得到 3 和 12。

## 3. if、elif、else 條件判斷（Q210、Q602）

```python
score = int(input())
if score >= 90:
    print("A")
elif score >= 60:
    print("B")
else:
    print("C")
```

條件由上往下判斷，只執行第一個成立的區塊。`==` 是比較是否相等，`=` 是指定值。冒號後的縮排表示哪些程式屬於該區塊。需要同時成立可用 `and`，至少一個成立可用 `or`。

## 4. for 和 range：重複固定次數（Q306、Q308）

```python
for i in range(1, 4):
    print(i)
```

輸出 1、2、3，各占一行。`range(起點, 終點)` **包含起點，不包含終點**；要走到 `n`，終點寫 `n + 1`。`range(3)` 則產生 0、1、2。若只需要重複次數、不使用迴圈變數，可以寫 `for _ in range(3):`。

## 5. 累加與累乘（Q306、Q308、Q902）

```python
total = 0
for number in range(1, 5):
    total += number
print(total)  # 10
```

`total += number` 等同 `total = total + number`。累加初值通常是 0，總和依序變為 1、3、6、10。累乘初值通常是 1，例如階乘：

```python
result = 1
for number in range(1, 5):
    result *= number
print(result)  # 24，也就是 1 × 2 × 3 × 4
```

結果若只要印一次，`print` 應放在迴圈外。

## 6. while 與 break：讀到結束值為止（Q702、Q710、Q810）

```python
numbers = []
while True:
    number = int(input())
    if number == -9999:
        break
    numbers.append(number)
print(numbers)
```

`while True` 持續重複，直到 `break` 離開迴圈。先判斷結束值再加入串列，才不會把 `-9999` 當成資料。結束值以題目規定為準。

## 7. 字串走訪與轉數字（Q308、Q802）

```python
text = "123"
total = 0
for character in text:
    total += int(character)
print(total)  # 6
```

`for` 可以逐一取出字串的字元，依序得到 `"1"`、`"2"`、`"3"`；每個字元仍是字串，要轉型才可相加。若字元不是數字，`int(character)` 會出錯，必須依題目輸入條件處理。

`ord("A")` 得到字元的 Unicode 整數代碼 65；`chr(65)` 則得到字元 `"A"`，可用於字元與代碼的轉換。

## 8. 字串索引、切片與反轉（Q404）

```python
text = "0123"
print(text[0])    # 0：第一個字元
print(text[-1])   # 3：最後一個字元
print(text[1:3])  # 12：取索引 1、2，不含 3
print(text[::-1]) # 3210：反轉
```

索引從 0 開始，切片終點不包含在內。需要保留前導零時，要用字串處理；若先轉成整數，`"0123"` 會變成 `123`。

## 9. 字串整理與分割（Q602、Q810、Q902）

```python
text = "  10  20 30  "
print(text.strip())   # 去除頭尾空白
print(text.split())   # ['10', '20', '30']
```

`strip()` 去掉頭尾空白與換行；`split()` 依空白切開，連續空白也可處理。切開後每項仍是字串：

```python
parts = "10 20 30".split()
numbers = []
for part in parts:
    numbers.append(int(part))
print(numbers)  # [10, 20, 30]
```

需要指定分隔符號時可以用 `"a,b,c".split(",")`。

## 10. list：儲存多筆資料（Q602、Q702、Q810）

```python
numbers = []
numbers.append(8)
numbers.append(2)
numbers.append(5)
print(numbers[0])  # 8
for number in numbers:
    print(number)
```

串列 `list` 可以儲存多個值，`append()` 加到最後，索引從 0 起算。`len(numbers)` 是數量、`sum(numbers)` 是總和、`max(numbers)` 和 `min(numbers)` 找最大最小值。最大最小值要求串列不是空的。

## 11. 排序與 tuple（Q702）

```python
numbers = [10, 2, 5]
ordered = sorted(numbers)
print(ordered)  # [2, 5, 10]
print(numbers)  # [10, 2, 5]，原本不變
```

`sorted()` 回傳新的排序串列；`numbers.sort()` 則直接修改原串列。數字要先轉為 `int` 再排序，否則字串 `"10"` 和 `"2"` 是依文字順序比較。

`tuple`（數組）同樣可依序保存多個值，但建立後不能像串列那樣直接修改項目。`tuple(numbers)` 可將串列轉成數組；兩個數組可以用 `+` 串接，`sorted(數組)` 的結果則是串列。

## 12. dictionary：鍵與值（Q602、Q710）

```python
mapping = {"A": 1, "J": 11}
card = "A"
if card in mapping:
    print(mapping[card])  # 1
```

字典用「鍵：值」配對；`mapping[card]` 以鍵查值，`card in mapping` 檢查鍵是否存在。新增或更新可寫 `mapping["Q"] = 12`。如果直接查不存在的鍵會產生 `KeyError`，因此先檢查很實用。

## 13. 函式、參數與 return（Q502、Q510）

```python
def compute(a, b):
    product = a * b
    return product

answer = compute(3, 4)
print(answer)  # 12
```

`def` 定義函式，`a`、`b` 是參數；呼叫時將 3、4 傳入。`return` 把結果交回呼叫處並結束函式；`print` 是顯示文字。兩者用途不同，題目要求回傳時不要只在函式內印出。

## 14. 雙迴圈：先理解列與欄（Q410）

先畫直角三角形，再進入等腰三角形：

```python
h = 3
for row in range(1, h + 1):
    for column in range(row):
        print("*", end="")
    print()
```

輸出：

```text
*
**
***
```

外層每跑一次處理一整列；內層每跑一次印一個星號。當 `row` 是 1、2、3，內層分別跑 1、2、3 次。`end=""` 讓每次 `print` 不換行；內層結束後的 `print()` 才換行。內層會在每次進入新的一列時重新從頭執行。

## 15. 雙迴圈：Q410 等腰三角形（重點）

題目輸入高度 `h`；第 `row` 列先印 `h - row` 個空格，再印 `2 * row - 1` 個星號。空格、星號分別用一個內層迴圈，兩者在每一列**依序**執行。

```python
h = int(input())
for row in range(1, h + 1):
    for column in range(h - row):
        print(" ", end="")
    for column in range(2 * row - 1):
        print("*", end="")
    print()
```

以 `h = 3` 為例，以下 `·` 代表一個空格，實際程式印出的是空格：

| 列 row | 空格 `h - row` | 星號 `2 * row - 1` | 輸出內容 |
| --- | --- | --- | --- |
| 1 | 2 | 1 | `··*` |
| 2 | 1 | 3 | `·***` |
| 3 | 0 | 5 | `*****` |

講解時可逐行追蹤：第一列先進入空格迴圈印兩次，再進入星號迴圈印一次，最後換行；外層進入第二列後，兩個內層迴圈重新執行。第三列的 `range(0)` 不會執行，所以沒有空格。

常見錯誤：忘記 `end=""` 會讓每個字元各占一行；把最後的 `print()` 放在內層也會提早換行；`range(1, h)` 會漏掉最後一列。若已理解雙迴圈，也可用字串重複簡寫成 `print(" " * (h - row) + "*" * (2 * row - 1))`。

## 補充：檔案讀寫與字串取代（Q902、Q906）

```python
with open("read.txt", "r", encoding="utf-8") as file:
    content = file.read()

numbers = content.split()
total = 0
for number in numbers:
    total += int(number)
print(total)
```

`with open(...)` 開啟檔案，區塊結束後自動關閉；`"r"` 表示讀取。`read()` 取得整份文字，搭配 `split()` 可切出空白分隔的數字。

```python
new_content = content.replace("old", "new")
with open("output.txt", "w", encoding="utf-8") as file:
    file.write(new_content)
```

`replace()` 回傳取代後的新字串，不會直接改變原字串。`"w"` 會覆寫指定檔案原有內容，使用時確認題目要求的檔名與寫入方式。
