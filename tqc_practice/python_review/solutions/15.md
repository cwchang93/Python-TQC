# 15 雙迴圈：等腰三角形：詳解

## 參考程式

```python
h = int(input())
for row in range(1, h + 1):
    for column in range(h - row):
        print(" ", end="")
    for column in range(2 * row - 1):
        print("*", end="")
    print()
```

## 說明

外層迴圈控制列數。每列先執行一個內層迴圈印空格，再執行另一個內層迴圈印星號；兩個內層迴圈是依序執行，並非彼此再巢狀。end="" 不換行，最後的 print() 才換到下一列。

以 h = 3 為例（· 代表一個空格，實際輸出是空格）：

| row | 空格 h-row | 星號 2*row-1 | 該列 |
| --- | --- | --- | --- |
| 1 | 2 | 1 | `··*` |
| 2 | 1 | 3 | `·***` |
| 3 | 0 | 5 | `*****` |

第一列的空格迴圈印兩次，星號迴圈印一次，接著換行；第二列重新執行兩個內層迴圈。第三列 range(0) 不執行，所以沒有前置空格。常見錯誤是把換行 print() 放進內層，導致每個字元各占一行。
